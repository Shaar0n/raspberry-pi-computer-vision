# Raspberry Pi Computer Vision Project Reports

This repository collects the final reports, supporting figures, and related artifacts for a Raspberry Pi computer-vision project completed in CV_LAB. The work covers image quality, camera setup, ISP behavior, TensorFlow Lite object detection, and face/object detection under variable lighting conditions.

## What is included

- `Setting_Up_Raspberry_Pi/` - Raspberry Pi setup report and supporting screenshots.
- `Setting_Up_A_Camera/` - Camera setup report and supporting screenshots.
- `ISP_Vs_RTFC/` - Image signal processing versus real-time facial recognition comparison report and visuals.
- `Real-Time_Facial_Recognition/` - Real-time face recognition report and supporting screenshots.
- `Object_Detection_TF_Lite/` - TensorFlow Lite object detection report and example outputs.
- `Lab_Final_Face_and_Object_Detection_Under_Variable_Lighting_Condtions/` - Final report on face and object detection in changing lighting conditions.
- `Image_Quality_Vs_Cv/` - Image quality versus computer vision report, example images, and sharpness experiments.
